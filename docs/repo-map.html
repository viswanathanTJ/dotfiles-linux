Dotfiles repo map

One git repo holds every config. Your home folder holds links into it, so an edit in either place is the same edit, and git diff shows it. Three things can't be links; each has its own sync path.

How the configs are wired

Links point from your home folder into the repo

Three kinds of config

Files are linked; Toshy and GNOME need a sync step

setup.sh

What each command does to a file in your home folder

CommandUse it when
./setup.shYou want the help: every app, every command
./setup.sh kitty tmux code toshyApply these apps; the repo version wins. all applies every app
./setup.sh -iNew machine: answer y/n per app, see the plan, then go
./setup.sh --adopt vscodeThis machine's version is the one to keep
./setup.sh --reset kittyTry the app with its own defaults; your config stays in the repo
./setup.sh --unlink kittyStop syncing an app but keep its current settings
./setup.sh --statusCheck nothing turned back into a plain file

Other names work too: code = vscode, toshy = keyboard, vim = nvim, fish = shell, btop = tools, docker = podman, workspaces = desktops.

Two routines

Day to day, and on a new machine

After changing a config

# edit in the app, in nvim, or in ~/dotfiles: same file
cd ~/dotfiles
git status; git diff
git commit -am "kitty: new split keys"
git tag m2                    # named checkpoint
git checkout m1 -- stow/kitty # roll one app back

# Toshy rules or GNOME settings changed?
reload-shortcuts              # Toshy: newest edit wins
./setup.sh desktops           # re-apply gnome/settings.sh

New machine

  1. sudo apt install git stow
  2. git clone <repo> ~/dotfiles; cd ~/dotfiles
  3. ./setup.sh -i, saying yes to packages and the apps you want
  4. Install Toshy as your normal user (commands in the README)
  5. Log out and back in so GNOME loads the extensions
  6. ./setup.sh toshy to copy your rules into Toshy
  7. ./setup.sh --status: every file should say linked

Some apps save by writing a new file and swapping it in, which replaces the link with a plain file. If --status shows PLAIN FILE, DIFFERS, run ./setup.sh --adopt <app> to take that version and link it again.

Repo layout

Where things live

~/dotfiles/
  setup.sh                 # the one command; no arguments = help
  README.md                # install commands for every program, full guide
  stow/<app>/…             # each app's files, laid out like your home folder
  keyboard/
    toshy_user_apps.py     # your Toshy rules
    sync-toshy-rules.py    # used by reload-shortcuts
  gnome/settings.sh        # GNOME settings, Toshy apply, resets
  docs/                    # keyboard docs, this page
  examples/                # templates: gitconfig, 90-local.fish (personal, not tracked)
Not in the repo on purpose: secrets, fish_variables, CopyQ history, sign-ins, Toshy's generated config, system setup outside the home folder.GNU Stow manual.
